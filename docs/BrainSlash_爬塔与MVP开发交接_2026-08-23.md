## 1. 交接结论

当前项目已经完成可玩的客户端核心闭环：

`Home → Gameplay → Result → 重玩 / 分享好友挑战 / 返回首页`

60 秒乱斗、四阶段导演、主题/题型/素材洗牌冷却、六类规则、多选与顺序判定、复杂规则安全教学、本地每日挑战、无服务端好友挑战、正式 Result、核心音效反馈和竖屏防重叠轨迹均已落地。

下一阶段的产品调整是：

1. 首页第一视觉位由“每日挑战”调整为可长期游玩的爬塔模式；
2. 60 秒乱斗继续保留在首页中部，承担快速开局与冲分；
3. 每日挑战和好友挑战降为辅助入口；
4. 爬塔通过塔层逐步解锁复杂规则，并提供永久进度、累计积分和检查点；
5. 同步补齐当前客户端 MVP 的上线缺口。

## 2. 产品定位与模式分工

### 2.1 爬塔模式

定位：长期主线、规则成长、逐层推进。

玩家进入一层，完成连续题目或阶段目标后结算该层，获得塔积分并推进最高层。每层结束自动保存，玩家可以继续、暂停或返回首页。

爬塔负责：

- 逐步介绍和解锁规则；
- 提供长期目标、检查点和累计成长；
- 让玩家自主选择玩一层还是连续玩较长时间；
- 为 60 秒乱斗扩充已掌握规则池。

### 2.2 60 秒乱斗

定位：一键开局、短局冲分、使用已掌握规则进行混合挑战。

首页中部继续保留高识别度主按钮，不进入主题选择页。新玩家的普通乱斗优先从已解锁规则池出题；每日挑战和好友挑战允许预览未解锁规则，但必须继续使用安全教学题。

### 2.3 每日挑战与好友挑战

- 每日挑战保留本地日期固定 Seed、七日配方、当日最佳和重玩闭环；
- 好友挑战保留分享参数重建同题、目标分 HUD、胜负结算和回敬挑战；
- 两者在首页降为小卡或辅助入口，不再占据第一视觉位。

## 3. 爬塔 MVP 规则草案

### 3.1 名词约束

规则解锁使用“塔层”，不直接使用当前玩家 XP 等级。

原因：现有玩家等级按累计 XP 计算，如果直接用于规则解锁，会导致解锁节奏受旧存档和刷题数量影响。玩家等级继续承担轻量成长展示；塔层承担玩法推进和规则解锁。

### 3.2 单层结构

- 单层目标时长：30–60 秒；
- 单层题量：约 8–15 题，根据题型和复杂度限流；
- 每层开始显示短标题、主要主题和本层规则；
- 每层结束展示本层得分、累计塔积分、最高层和下次解锁；
- 每层结束立即保存；
- 每 5 层设置检查点；
- 失败后回到最近检查点或重试当前层，不从第一层清空全部进度；
- 前 30 层为首章设计节奏，30 层后再进入程序化无尽循环。

### 3.3 建议解锁表

| 塔层 | 新内容 | 教学要求 |
|---:|---|---|
| 1 | 标准规则，2–3 个目标 | 基础斩击引导 |
| 3 | 炸弹 / 禁区 | 首题无惩罚 |
| 5 | 多目标 | 明确“全部斩完才成功” |
| 7 | 顺序 | 显示顺序并允许分次划动 |
| 10 | 反向 | 首题无惩罚，并持续显示反向状态 |
| 13 | Stroop | 明确判断文字还是颜色 |
| 15 | 两规则白名单组合 | 只组合已掌握规则 |
| 20 | 高压混合层 | 不同时叠加最高数量、最高速度和双规则 |
| 25 | 精英层 / 特殊事件 | 使用既有规则，不引入新判定系统 |
| 30 | 首章终点 / 无尽入口 | 记录首章通关状态 |

第 5 层应在新玩家首次游玩约 5–10 分钟内可达，避免规则解锁过慢。所有复杂规则第一次出现时复用当前 `RuleTutorial` 安全教学和失败重试机制。

### 3.4 积分与进度

需要区分两个数值：

- **塔积分**：永久累计，用于成长、称号或里程碑，不作为公平竞技成绩；
- **最佳记录**：最高层、单次连续爬塔最高分、最高 Combo，用于自我挑战或好友分享。

重复刷低层可以获得基础反馈，但首次通关奖励应更高，避免低层成为最高效率的永久积分来源。首版不增加体力门槛、付费重置或复杂奖励经济。

## 7. 不属于当前纯客户端 MVP 的项目

以下内容暂不作为本轮阻塞项：

- 云端排行榜、真实好友列表和附近排名；
- 跨设备云存档；
- 服务端每日挑战、防作弊和权威积分；
- 实时 PvP、观战或好友在线状态；
- 商城、抽卡、签到、任务大厅、宠物和复杂养成；
- Chaos 扩展机制。

本地最高层、塔积分、每日最佳和无服务端分享挑战可以继续作为首发方案，但产品文案不能暗示它们是不可篡改的全服成绩。
