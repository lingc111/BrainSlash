二、重要原则
======

不要用代码模拟复杂纸张纹理
-------------

不要为了纸张质感编写大量：
    Graphics.lineTo(...)
    Graphics.rect(...)
    随机噪点
    随机线条
    随机锯齿

这会：

* 增加代码复杂度

* 很难达到视觉稿效果

* 不方便未来由美术替换

* 产生不稳定的视觉结果

正确方案：
    透明 PNG / SpriteFrame
    +
    Cocos Sprite

代码只负责：
    位置
    尺寸
    状态
    交互
    动态内容

美术纹理由图片负责。

十四、Sprite 替换规则
==============

首先检查当前 Scene。

找到对应 Graphics 占位节点。

例如：
    Background
    DailyChallenge/PaperBackground
    DailyChallenge/StartButton/BrushBackground
    BrawlButton/YellowPaper
    ReverseDayCard/Paper
    FlagHunterCard/Polaroid

尽量：

**保留原节点名称。**

不要删除整个节点后重新创建结构。

优先：
    Graphics
    ↓
    Sprite

或者：

在原节点下创建视觉 Sprite 子节点。

确保：

* 原 Button 节点仍然存在

* 点击区域不变

* Label 不变

* Controller 引用不失效

* Widget 不失效

* Layout 不失效

* * *

十五、不要破坏点击区域
===========

例如：
    60秒乱斗

黄色剪纸边缘有锯齿。

Button 的 Hit Area：

不要跟着锯齿变得很难点击。

继续使用规则矩形作为点击区域。

也就是：
    视觉不规则
    交互规则

这是移动游戏更合理的方案。

* * *

十六、不要让 Sprite 自动改变已有布局
======================

替换 Sprite 后：

检查：
    UITransform
    Content Size
    Anchor
    Position
    Scale
    Widget

不要因为 SpriteFrame 原始尺寸改变节点 Layout。

应该：

使用现有 UITransform 尺寸作为视觉布局基准。

素材通过：
    CUSTOM size

或适当 Sprite Size Mode 适配。

不要让：
    RAW

尺寸直接破坏现有布局。

十七、关于拉伸
=======

纸张素材不应该被严重非等比拉伸。

特别是：
    胶带
    撕纸边缘
    笔刷
    锯齿

如果一个素材需要适配不同宽度：

优先考虑：

### 方案 A

固定设计比例 + Scale。

### 方案 B

合理使用 9-Slice。

但只有满足以下条件时使用 9-Slice：

* 中部纹理可安全拉伸

* 四边/角不能变形

* Border 已正确设置

不要为了使用 9-Slice 强行改变艺术效果。
