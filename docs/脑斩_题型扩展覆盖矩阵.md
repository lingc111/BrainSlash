## 明确排除

| 文档条目 | 状态 | 原因 |
| --- | --- | --- |
| 瞬时记忆位置、颜色、顺序 | 产品决定排除 | 不实现任何瞬时记忆题 |
| 移动目标追踪 | 产品决定排除 | 不实现追踪题 |
| 连续指令、规则中途切换 | 产品决定排除 | 每题只有一个固定规则 |
| 地理方向判断、地理位置排序 | 产品决定排除 | 不实现地理方位与空间排序 |
| 国家/国旗、国家/地标双向题 | 素材暂缓 | 依赖新增图片素材 |

## 诗词限制

- 完整诗句只可作为静态题干。
- 所有可斩诗词答案和干扰片段去除标点、空格后必须为 1–4 个汉字。
- 构建审计发现超长片段时直接失败，不在运行时截断。
