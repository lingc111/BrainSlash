# 《脑斩 / Brain Slash》MVP 主题与题库设计 v1.0

> 文档状态：内容开发基线  
> 依赖文档：`微信小游戏_UI设计总提示词_v1.1.md`、`技术架构与MVP功能清单_v1.0.md`  
> 目标：六大首发主题能够支撑连续游玩、每日挑战和好友同题挑战，同时保持 0.2–0.5 秒识别与街机动作感。

## 1. 内容总原则

### 1.1 内容不是“题目列表”，而是战斗弹药

每题必须满足：

- 提示优先为 2–8 个汉字或一个短表达式；
- 答案表现为场上 2–6 个可斩目标，不出现传统四选一按钮；目标上限按内容可读性分级，不把 6 个目标作为所有题型的通用难度；
- 玩家应在 1–3 秒内完成理解和动作；
- 每题只考一个清晰知识点，复杂度来自规则和动作，不来自长题干；
- 干扰项必须“像答案但可快速排除”，不能靠冷知识或文字陷阱；
- 同一时刻最多叠加 2 个复杂规则；
- 首次复杂规则使用无惩罚安全教学题；
- 任何题型都必须先通过唯一答案、可达路径和危险目标间距校验。

题目包装使用“斩、砍、追、猎、破阵”等动作语言。不要出现“请作答”“选择正确答案”“本题考查”等教学式文案。

### 1.2 首发六大主题

| 主题 ID | 对外名称 | 内容核心 | 内容来源 |
|---|---|---|---|
| `math_blitz` | 闪电心算 | 运算、奇偶、大小、序列 | 参数化生成 |
| `word_hunt` | 单词猎场 | 高频英文、类别、反义、拼写 | 审核词库 + 模板 |
| `hanzi_blade` | 字刃江湖 | 成语补字、偏旁、反义、字序 | 审核词库 + 模板 |
| `flag_strike` | 旗阵突袭 | 国旗、国家、首都、大洲 | 审核国家库 + 图片 |
| `daily_instinct` | 生活本能 | 物品用途、公共图标、时间 | 审核事实库 + 图标 |
| `vision_overdrive` | 眼力超频 | 数量、方向、异类、颜色、规律 | 参数化生成 |

这些名称只表现挑战感，不在首页展示“数学、语文、英语”式学科目录。

## 2. 内容数据分层

```text
Theme 主题
└─ Family 题型族
   ├─ Template 出题模板
   ├─ Fact / Lexeme 审核素材
   ├─ DifficultyBand 难度参数
   └─ RuleProfile 可叠加规则
      ↓
QuestionGenerator
      ↓
QuestionInstance 本局题目
```

### 2.1 题型模板

模板定义提示、答案关系、目标外观和干扰项策略，不保存某一道固定题。例如 `math.addition` 根据难度生成 `7+8`，再生成 3–5 个接近但不重复的数值目标。

### 2.2 审核素材

英语词义、成语、国家信息和生活事实必须来自版本化素材库。素材只描述事实，不决定本局规则和位置。

### 2.3 运行时题目签名

```ts
interface ContentSignature {
  themeId: string;
  familyId: string;
  factIds: string[];
  answerKey: string;
  ruleIds: string[];
  difficulty: 1 | 2 | 3 | 4 | 5;
}
```

同一个签名在一局内不得重复。仅改变目标位置、形状或颜色不算新题。

## 3. 循环游玩与防重复

### 3.1 60 秒乱斗内容编排

一局预计出现 24–36 题，实际由玩家反应速度决定。

| 时段 | 内容策略 | 规则策略 | 目标数 |
|---|---|---|---:|
| 0–15 秒 | 2 个熟悉主题交替，建立手感 | 标准为主 | 2–3 |
| 15–40 秒 | 六主题洗牌，每个主题出现后才开启下一轮 | 单个复杂规则 | 3–5 |
| 40–60 秒 | 玩家表现较好的主题权重略升 | 最多 2 个复杂规则 | 通常 4–5；纯视觉单规则可到 6 |

不要让“擅长主题权重提高”变成持续刷同一主题：单主题占整局题量不得超过 30%，相同主题最多连续 2 题。

### 3.2 三层洗牌袋

1. `ThemeBag`：六主题加权洗牌；
2. `FamilyBag`：主题内题型族洗牌；
3. `FactBag`：审核素材无放回抽取。

每层抽取都受冷却约束：

- 同一题型族至少间隔 3 题；
- 同一答案至少间隔 8 题；
- 同一审核素材至少间隔 20 题；
- 同一提示文案最多连续使用 2 次；
- 同一种目标轮廓布局至少间隔 2 题；
- 同一复杂规则最多连续 2 题，之后至少插入 1 道标准题。

如果候选全部处于冷却期，优先放宽视觉布局冷却，再放宽题型冷却，最后才允许重复素材；绝不放宽唯一答案与公平性校验。

### 3.3 表现自适应

每个主题维护最近 12 题的正确率与中位反应时间：

- 正确率 ≥ 85% 且反应快：难度权重 +1；
- 正确率 60%–84%：保持；
- 正确率 < 60% 或连续错 2 题：下一题降一级且不用复合规则；
- 连续错 3 题：插入熟悉主题的标准安全题；
- 不在局内弹出“你需要学习”之类提示。

好友挑战使用相同 seed 和固定难度序列，不应用个体自适应，以确保题序可复现。

## 4. 全局难度定义

| 等级 | 玩家负荷 | 题面 | 规则 | 运动 |
|---|---|---|---|---|
| D1 | 立即识别 | 2–3 个高差异目标 | 标准 | 慢速直线或轻漂浮 |
| D2 | 一步判断 | 3–4 个目标，近似干扰 | 标准或炸弹 | 中低速 |
| D3 | 判断 + 抑制 | 4–5 个目标 | 单个 Reverse/Multi/Order/Stroop | 中速可预测轨迹 |
| D4 | 双条件 | 通常 4–5 个目标 | 两规则白名单组合 | 中高速但保持安全路径 |
| D5 | 高压精确动作 | 4–5 个高质量近似干扰 | 两规则 + 短时间窗 | 高速，不缩小命中区 |

D5 只提高认知和节奏压力，不通过微小字号、目标重叠、不可预测瞬移或缩小触控区制造难度。

### 4.1 竖屏目标密度与运动可读性

目标数量必须同时受题型和规则负荷约束：

| 内容类型 | 同屏目标上限 |
|---|---:|
| 运算、单项填字、成语、词义、地理事实 | 4 |
| 奇偶/倍数、英语分类、生活分类等集合判断 | 5 |
| 图形、数量、颜色、方向等纯视觉题 | 6 |
| 任意双规则组合 | 在阶段基础数量上再减少 1 |

- `hanzi-order` 为完成四字成语允许 4 个汉字；叠加炸弹时允许总数为 5；
- 竖屏阵型每行最多两个目标：4 个使用 `2×2`，5 个使用 `2+1+2`，6 个使用 `2×3`；
- 目标视觉间距不小于 48 px，命中区域不得重叠，中央必须保留连续斩击通道；
- 数字、汉字、单词以及携带文字的目标禁止持续自转；只允许 `±8°–12°` 的入场倾斜，并在 180–240ms 内回正；
- 难度提升优先增加题义、规则组合和时间压力，不同时叠加数量、速度与旋转压力；
- 方向、顺序、Stroop 等题型的运动不得改变正在被判断的视觉属性。

## 5. 规则兼容矩阵

符号：`✓` 默认支持；`△` 仅指定题型支持；`—` 禁止。

| 主题 | 标准 | 反向 | 多目标 | 顺序 | Stroop | 炸弹 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| 闪电心算 | ✓ | ✓ | ✓ | ✓ | — | ✓ |
| 单词猎场 | ✓ | ✓ | ✓ | △ | △ | ✓ |
| 字刃江湖 | ✓ | ✓ | ✓ | ✓ | — | ✓ |
| 旗阵突袭 | ✓ | ✓ | ✓ | — | — | ✓ |
| 生活本能 | ✓ | ✓ | ✓ | △ | — | ✓ |
| 眼力超频 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

### 5.1 允许的双规则组合

- `Reverse + Multi`：分类题，翻转后仍有 2–3 个明确目标；
- `Multi + Order`：数值、字母或成语字序；
- `Stroop + Reverse`：只在玩家完成两者独立教学后；
- `Bomb + Reverse`：炸弹保持绝对禁止，不参与集合翻转；
- `Bomb + Multi`：生成器必须验证连斩路径远离炸弹；
- `Bomb + Order`：仅 D4–D5，炸弹不得位于必经轨迹附近。

### 5.2 禁止的组合

- `Reverse + Order`：玩家难以理解“顺序的反向”究竟指答案集合还是动作顺序；
- `Stroop + Order`：双重工作记忆负担过高；
- `Stroop + Multi + 任意规则`：超过两个复杂规则；
- 任意会令正确目标为 0 或超过 4 个的组合；
- 任意让炸弹成为正确答案的组合。

## 6. 主题一：闪电心算

### 6.1 主题定位

用大数字、符号牌和短表达式形成最快的“看懂—出刀”节奏。答案始终为整数，首发不出现分数、小数、负数和括号嵌套。

### 6.2 题型族

| Family ID | 提示示例 | 目标构造 | D1–D5 | 规则 |
|---|---|---|---|---|
| `math.add` | `7+8` | 正解附近 ±1/±2/±3 | 和 10 → 99 | 标准、反向、炸弹 |
| `math.subtract` | `14-6` | 正解附近值 | 不借位 → 两位借位 | 标准、反向、炸弹 |
| `math.multiply` | `6×7` | 同乘法表邻近积 | 2/5/10 → 6/7/8/9 | 标准、反向、炸弹 |
| `math.divide` | `36÷6` | 整除结果附近值 | 除数 2/5 → 3–9 | 标准、反向、炸弹 |
| `math.parity` | `斩偶数` | 奇偶混合整数 | 2 位 → 3 位 | 标准、反向、多目标、炸弹 |
| `math.compare` | `斩最大的` | 不重复数值 | 差值大 → 差值小 | 标准、反向、炸弹 |
| `math.threshold` | `斩大于20` | 阈值两侧数值 | 单目标 → 多目标 | 标准、反向、多目标 |
| `math.missing` | `□+6=14` | 唯一缺项 | 单步 → 乘除混合 | 标准、反向 |
| `math.sequence` | `3,6,9,?` | 唯一下一项 | 等差 1–5 → 交替规律 | 标准、反向 |
| `math.expression_compare` | `斩值最大的` | 2–4 个短表达式 | 单运算 → 不同运算 | 标准、反向 |
| `math.sort_asc` | `从小到大` | 3–4 个数 | 差值大 → 近似数 | 多目标、顺序、炸弹 |
| `math.sort_desc` | `从大到小` | 3–4 个数 | 差值大 → 近似数 | 多目标、顺序、炸弹 |
| `math.multiples` | `斩3的倍数` | 倍数与近似值 | 2/5 → 3/4/6/8 | 标准、反向、多目标 |
| `math.pair_sum` | `凑成10` | 唯一互补数对 | 和 10 → 和 50 | 多目标 |

### 6.3 参数范围

| 难度 | 加减 | 乘除 | 分类 | 顺序 |
|---|---|---|---|---|
| D1 | 0–10，不借位 | ×2、×5、×10 | 1 位奇偶 | 3 个、差 ≥ 3 |
| D2 | 0–20，可借位 | 2–5 乘法表 | 1–2 位 | 3 个、差 ≥ 2 |
| D3 | 0–50 | 2–9 乘法表 | 2 位阈值/倍数 | 3–4 个 |
| D4 | 0–99 | 整除 2–9 | 多目标 + Reverse | 4 个近似数 |
| D5 | 两个短表达式比较 | 乘除混合比较 | 3 位数分类 | 4 个 + 炸弹 |

### 6.4 生成约束

- 减法结果不为负；
- 除法必须整除；
- 表达式视觉长度不超过 7 个字符；
- 干扰项不得重复，不得超出该难度数值范围；
- `pair_sum` 只能存在一组互补答案；
- `sequence` 首发只使用等差、等比 2 倍和两步交替三类可快速识别规律；
- “最大/最小”题禁止相同数值；
- 表达式比较题的结果必须互不相同。

## 7. 主题二：单词猎场

### 7.1 主题定位

只使用高频、短、单义优先的英文词。避免冷僻词、长句、语法术语和需要上下文才能确定的多义词。

### 7.2 题型族

| Family ID | 提示示例 | 目标 | 规则 |
|---|---|---|---|
| `word.zh_to_en` | `苹果` | apple / milk / bread | 标准、反向、炸弹 |
| `word.en_to_zh` | `TIGER` | 老虎 / 狮子 / 熊猫 | 标准、反向、炸弹 |
| `word.category` | `斩动物` | cat / chair / lion / book | 标准、反向、多目标 |
| `word.opposite` | `HOT的反义` | cold / fast / new | 标准、反向 |
| `word.initial` | `斩B开头` | book / cat / bread / sun | 标准、反向、多目标 |
| `word.missing_letter` | `C_T` | A / O / U / E | 标准、反向 |
| `word.length` | `斩4字母` | book / sun / apple / pen | 标准、反向、多目标 |
| `word.alphabetical` | `字母顺序` | ant / cat / dog | Multi + Order |
| `word.color_stroop` | `砍字体颜色` | 彩色 RED/BLUE/GREEN/YELLOW | Stroop、Stroop + Reverse |

`word.color_stroop` 的答案由字体实际颜色决定，不由单词含义决定；目标必须同时用色块底纹或色形图标辅助，避免只靠文字颜色。

### 7.3 首发词库：96 个词

每个词只绑定一个首发主释义。存在常见多义的词，仅在类别或图片上下文唯一时使用。

#### 动物 `animal`

`cat 猫`、`dog 狗`、`bird 鸟`、`fish 鱼`、`horse 马`、`cow 牛`、`sheep 羊`、`rabbit 兔子`、`tiger 老虎`、`lion 狮子`、`monkey 猴子`、`panda 熊猫`

#### 日常物品 `object`

`book 书`、`pen 钢笔`、`key 钥匙`、`cup 杯子`、`chair 椅子`、`table 桌子`、`door 门`、`window 窗户`、`phone 手机`、`clock 时钟`、`bag 包`、`box 盒子`

#### 动作 `action`

`run 跑`、`jump 跳`、`swim 游泳`、`eat 吃`、`drink 喝`、`read 阅读`、`write 写`、`open 打开`、`close 关闭`、`sit 坐`、`stand 站`、`sleep 睡觉`

`big 大的`、`small 小的`、`hot 热的`、`cold 冷的`、`fast 快的`、`slow 慢的`、`happy 高兴的`、`sad 难过的`、`old 旧的`、`new 新的`、`clean 干净的`、`dirty 脏的`

#### 颜色与数字 `basic`

`red 红色`、`blue 蓝色`、`green 绿色`、`yellow 黄色`、`black 黑色`、`white 白色`、`one 一`、`two 二`、`three 三`、`four 四`、`five 五`、`ten 十`

### 7.4 固定反义词对

`big ↔ small`、`hot ↔ cold`、`fast ↔ slow`、`happy ↔ sad`、`old ↔ new`、`clean ↔ dirty`、`open ↔ close`、`sit ↔ stand`

只从这 8 组生成反义题，不自动推导其他词的反义关系。

### 7.5 生成约束

- D1–D2 英文目标长度不超过 6 个字母；
- D3 以后可使用 7–8 个字母，但不缩小字号；
- 翻译题的干扰项优先来自同一类别；
- `missing_letter` 只使用删除一个字母后仍能唯一还原的词；
- 不使用 `orange`、`bat`、`light` 等常见多义词做无上下文翻译题；
- 字母顺序最多 4 个短词，比较采用英文拼写，不按中文翻译；
- Stroop 只使用 red、blue、green、yellow 四个词和四种显示色。

| `vision.size` | `斩最大的` | 同形不同尺寸 | 标准、反向 |
| `vision.color` | `斩蓝色` | 同形不同色 | 标准、反向、多目标 |
| `vision.stroop` | `砍字体颜色` | 颜色词与显示色冲突 | Stroop、Stroop + Reverse |
| `vision.pattern` | `下一个` | AB、AAB、ABC 图形序列 | 标准、反向 |
| `vision.order_size` | `从小到大` | 3–4 个同形目标 | Multi + Order |
| `vision.order_count` | `从少到多` | 3–4 个图元组 | Multi + Order |
| `vision.symmetry` | `斩对称` | 对称与非对称轮廓 | 标准、反向、多目标 |
| `vision.match_pair` | `斩同一对` | 两个同形同纹理目标 | Multi |

### 11.3 基础视觉字典

- 形状：圆、方、三角、六边形、星形、菱形；
- 方向：上、下、左、右；
- 颜色：红、蓝、绿、黄；
- 纹理：实心、横纹、点纹、空心；
- 图元数量：1–9；
- 旋转角：0°、90°、180°、270°；
- 尺寸级别：S、M、L、XL。

危险语义保留 Danger 红。普通颜色题使用红色时，炸弹必须额外依靠尖刺形、危险图标和专用轮廓区分；若同题容易产生语义冲突，则禁用炸弹。

### 11.4 难度参数

- D1：单属性差异，2–3 个目标；
- D2：单属性近似，3–4 个目标；
- D3：忽略一个无关属性，例如看方向而忽略颜色；
- D4：Stroop、Multi 或 Order，最多 6 个纯视觉目标；双规则时最多 5 个；
- D5：两规则白名单组合，但真实位置和命中体保持稳定。

### 11.5 生成约束

- `odd_shape` 只能有一个异类；
- 数量题中图元不能重叠，且一眼可数；D1–D3 不超过 7 个；
- 颜色不能是唯一危险提示；
- 序列规律首发仅 AB、AAB、ABB、ABC 和固定旋转五类；
- 对称题只用沿垂直轴可清晰判断的轮廓；
- 目标运动不得改变被考查属性，例如方向题的箭头不能在运动中旋转；
- 所有带文字或数字的目标只在入场时轻微倾斜，180–240ms 内回正，之后不持续自转；
- 尺寸题比较视觉外接尺寸，不混用不同形状导致面积歧义。

## 12. 首发内容量与组合规模

| 主题 | 题型族 | 审核素材 / 参数 | 理论题面规模 | 首发最低验收 |

| 闪电心算 | 14 | 5 档数值范围 | 20,000+ | 连玩 5 分钟无同签名重复 |
| 单词猎场 | 9 | 96 词、8 反义对 | 1,500+ | 每种题型至少 20 个有效实例 |
| 字刃江湖 | 7 | 90 成语、48 偏旁字、16 反义对 | 1,000+ | 成语和错字全部人工审核 |

## 13. 模式内容配方

### 13.1 60 秒乱斗

- 六主题混合；
- 每局先抽取一个“主主题”，权重 25%，其余主题均分 75%；
- 0–15 秒至少包含一道眼力题和一道心算题，迅速建立节奏；
- 15 秒后开放语言和地理题；
- 复杂规则教学未完成时，不在乱斗中直接生成相应规则的惩罚题。

### 13.2 今日挑战

每天一个挑战化名称和一个主题配方：

| 名称 | 主题权重 | 规则特征 |
|---|---|---|
| `偶数猎杀` | 心算 60% + 眼力 40% | 奇偶、多目标 |
| `反向日` | 六主题混合 | Reverse 权重提高 |
| `国旗猎人` | 地理 70% + 眼力 30% | 旗帜识别、Multi |
| `成语连斩` | 汉字 70% + 眼力 30% | 补字、Order |
| `颜色骗局` | 眼力 70% + 英语 30% | Stroop |
| `生活快手` | 生活 70% + 眼力 30% | 用途、图标、Bomb |
| `极速混战` | 六主题均衡 | 高速度，规则权重正常 |

日期只决定配方与 seed，不更改题目事实。七种配方轮换，内容版本参与 seed，保证同日同版本同题。

### 13.3 好友挑战

- 完整复用发起者的 `seed + contentVersion + recipeId`；
- 固定题序、规则、目标属性和玩法运动 RNG；
- 不固定纯装饰粒子 RNG；
- 挑战目标只显示分数，不提前泄露题目；
- 内容版本不兼容时标记挑战过期，回退到普通乱斗。

## 14. 干扰项设计

### 14.1 高质量干扰项优先级

1. 同类别近邻；
2. 常见误差或形近项；
3. 同长度、同量级或同视觉结构；
4. 其他明显错误项。

示例：

- `7+8`：使用 14、16、13，不使用 99；
- `TIGER`：使用狮子、熊猫，不使用桌子；
- `画龙点□`：使用晴、精、情，不使用水；
- 日本国旗：D1 使用巴西/加拿大，D4 才使用结构或配色更接近的旗帜；
- 手电筒用途：使用拍照、测温，不使用“会飞”；
- 向左箭头：使用其他方向，不使用完全不同图标。

### 14.2 禁止干扰项

- 另一个合理答案；
- 依赖方言、地区、年代或专业背景才能排除的答案；
- 通过颜色直接泄露正确性；
- 侮辱、恐怖、医疗、法律、政治或未成年人不适内容；
- 文字长度明显异常，以排版而非知识暴露答案；
- 低清或裁切后无法辨认的图像。

## 16. 内容生产与审核流程

```text
策划录入素材
→ Schema 校验
→ 自动唯一性检查
→ 自动生成 20–100 个实例
→ 固定 seed 批量截图
→ 文字/事实一审
→ 规则与歧义二审
→ 真机可读性抽测
→ 标记 reviewed
→ 进入内容版本
```

### 16.1 自动检查

- ID、标签和素材引用完整；
- 同题目标不重复；
- 正确目标数在规则允许范围；
- Reverse 后正确集合非空；
- Order 序列覆盖全部必斩目标且无重复；
- 炸弹不在正确集合；
- 提示长度、目标文本长度和字号预算合格；
- 英文大小写和词义映射一致；
- 成语与固定字序一致；
- 国家 ISO2、名称、旗帜、首都字段齐全；
- 生活用途不存在同题双解；
- 视觉题只有唯一规律或唯一异类。

### 16.2 人工审核

- 是否能在 0.5 秒内理解提示；
- 是否像街机目标而非试卷选项；
- 是否存在语境、地区、年龄或知识版本歧义；
- Reverse 后是否仍能快速理解；
- 多目标路径是否自然；
- 错误是否来自玩家判断，而非图片模糊或字体问题；
- 题目是否包含敏感、时效或专业建议内容。

## 17. 内容禁区

首发题库明确排除：

- 医疗诊断、用药、急救步骤；
- 法律责任、交通法规细节和地区政策；
- 政治人物、时事、赛事比分和动态排名；
- 国界、领土争议和带立场的国家归属；
- 宗教判断、民族刻板印象和价值评判；
- 食物是否“健康”、症状应该如何处理等情境题；
- 冷僻成语、网络流行语、方言和多音字读音；
- 英语长句、语法名称和多义词无上下文翻译；
- 依赖精细色差、微小纹理或低端屏幕难以区分的题；
- 需要停下来阅读解释才能知道答案的题。

## 18. 数据来源与版本维护

- 国家短名、ISO 代码和区域分组参考[联合国统计司 M49](https://unstats.un.org/unsd/methodology/m49/)；
- 汉字、成语写法在正式上线前按国家语言文字规范工具复核，教育部介绍的规范词典覆盖规范汉字、常用词和易错写法；
- 英语首发词库以高频基础词为原则，难度标签参考 CEFR Pre-A1/A1 的基础词汇能力描述，不宣称本游戏是语言课程；
- 所有外部事实只在内容生产阶段导入，运行时不联网抓取；
- 每次修改国家、词义、成语或生活事实时提升 `contentVersion`，并重新跑固定 seed 回归。

## 19. 上线验收标准

- 六主题均至少有 5 个可上线题型族，且每个题型有 D1–D3；
- 心算与眼力各至少有 10 个程序化生成器；
- 英语 96 词、成语 90 条、国家 48 个、生活用途 48 组全部完成双人审核；
- 六类规则在全题库中都有稳定内容承载，但不是每个主题强行支持所有规则；
- 任意主题连续玩 5 分钟不出现同签名题；
- 60 秒混合局中同主题占比不超过 30%，同主题不连续超过 2 题；
- 1000 个随机 seed 生成无空答案、无双解、无重复目标、无非法规则组合；
- 100 个固定 seed 在不同设备产生相同题序；
- 低端真机上目标文字、图标和旗帜均清晰，命中体不因内容长度缩小；
- 内容整体首先表现为高速街机动作，不出现教育 App、四选一答题卡或长文本讲解。

## 20. 实施顺序

1. 先实现心算 `add/parity/sort_asc` 与眼力 `odd_shape/direction/stroop` 六个纵切题型；
2. 建立题型配置、素材库、确定性 RNG、冷却和签名系统；
3. 接入英语 96 词和汉字成语库；
4. 制作并逐条验收 48 面国旗和 60 个生活图标；
5. 跑 1000 seed 自动检查与 100 seed 截图回归；
6. 真机连续游玩，调整干扰项相似度、题时和主题权重；
7. 冻结 `contentVersion = 1.0.0`，用于首个好友挑战版本。
